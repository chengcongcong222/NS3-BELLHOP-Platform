# 规划型算法扩展验收

已实现服务端 C++ 包与 XML 参数描述驱动的规划型 MAC 接入。正式默认目录只安装自适应 TDMA；教学示例通过独立编译参数安装验证，测试后已恢复默认目录。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| 旧自适应 TDMA 与注册包 | 相同输入逐发送机会一致，重复运行确定 |
| 模式 A 普通通信 | 注册包发送 8 次，送达 8 次，无融合业务 |
| 模式 A 方位融合 | 注册包发送 6 次，送达 6 次，形成 1 轮融合 |
| 模式 B 普通通信 | 注册包发送 8 次，目标交付 0；真实波形接收记录保留，未伪造解码 |
| 模式 B 方位融合 | 注册包发送 6 次，目标交付 2；未满足本案例报告门槛，无融合 |
| 第三方示例 | 仅通过 CMake 注册目录安装；降序参数使节点 1 先发送；模式 A/B 均完成 |
| 保存与重开 | 算法 ID、版本、包摘要、参数保持一致 |
| 重新运行 | 原冻结配置重新执行完成；缺包／错误版本／未知或非法参数明确拒绝 |
| 执行程序身份 | 启动后、发送命令前检查实际子进程 SHA256，错配时无仿真输入 |
| 浏览器 | 实际后台及 Worker 目录；修改秒输入成功，两个视口无横向溢出，用户草稿未改变 |

模式 B 的多径失真按当前真实算法产生，统计不等于算法接入失败。当前 SDK 不改变接收判定或制造 CRC 成功。
