# 环境计算与科研工作台收口

修改前检查点：`34d259b03596f2f482fef6e08155fcdb78a0bd50`。

## 范围与顺序

1. 冻结传输损失展示入口，保留 Runtime 使用的传播损失；声线只画真实路径，不伪造强度热力图或地形。
2. 移除无选择意义的计算模式。提供均分深度采样输入，解释距离采样间隔。历史自定义采样不静默重写。底质、声束、角度进入高级设置。
3. 固定事件提示栏高度；桌面端时间轴只占左侧，右侧日志跨行延伸。
4. 统计、日志独立外壳；全系统统一页面底色、面板、标题、内容四层浅色体系，保留打印可读性。
5. 前端测试、构建、实际浏览器布局验证，避免事件切换导致画布跳变。

## 声场正确性后续门禁（不能用 UI 完成冒充）

- 档位必须区分求解收敛与离线查询误差验证；仅预生成方案，选中后计算，缓存复用，不批量填满磁盘。
- 规则网格、关键深度补点、非网格独立位置验证与预算上限。
- 全轨迹覆盖与频率检查；不足时启动前补算并生成不可变版本，不进 Runtime 热路径。
- 不把零距离的无到达推广为大片近距离不可达；不以附近路径强行填充无到达。
- 模式 B 多径响应不能直接按路径序号插值。未验证区域应明确报告，不声称精度足够。
- WOA 不提供海底材料；底质只能是有来源的参数或显式模型假设。

## 本轮完成

- 声学结果页只保留真实声线路径。两种线色区分初始发射方向，不表示声强；没有把声线路径画成无法验证的强度热力图。发射深度和角度可筛选，筛选角度不改变坐标范围。历史环境缺少声线时明确提示，不借用其他深度的数据。
- 移除只有一个选项的计算模式。收发深度以起点、终点、点数均分，点击“应用均分”才替换采样数组，随后通过现有保存和计算接口提交。保留自定义数组入口；打开历史环境不会自动改写旧采样。
- 距离采样直接显示对应米数间隔，包含首尾位置。点数不是时间采样频率或声束数；更密的网格也不自动等于精度合格。
- 海底材料、波束数与发射角放在高级设置中；没有从 WOA 杜撰底质参数，也没有声称现有默认值是官方通用推荐。
- 事件提示栏固定高度。桌面端时间轴占左、中两栏，右侧观察栏延伸到底部；窄屏保留顺序排布。运行统计与日志使用独立白色面板、浅蓝标题、明确边框；日志条目分隔，当前事件高亮。
- 首页、案例、环境步骤、信道图和结果分析沿用一致的浅灰页面底色、白色内容面板、浅蓝标题。保持深色文字和打印样式，没有迁入新的图表库或图片资源。

没有改动后端、算法、运行时事件、历史环境或已有运行。单节点角色与算法集成等更早阶段的改动保留在前置检查点中，本轮不重新实现。

## 后续顺序与边界

1. 先形成三档候选采样方案及预算预览：快速检查、常规试验、精度核查。这是平台自己的待验证方案，不冠以官方推荐。根据当前水深、距离、SSP 变化与目标节点深度生成；用户仍可修改单项；仅计算选中的方案。
2. 用独立非网格测试位置、波束数和积分步长收敛检查确定档位参数。分别验收到达/无到达分类、时延与增益误差；模式 B 还要验证多径关联，不能按路径序号直接混合。
3. 再接入启动前全轨迹覆盖检查、离线补算与版本固定。禁止在 Runtime 中计算 Bellhop，禁止修改已发布资源或自动换成预置环境。
4. 当前查询中的最近采样点及无到达处理已受 ADR-0001 2.36/2.39 约束。若上述验证要求改变查询语义，应先评审 ADR；本轮未改该冻结规则。

这四项仍待实施，本次交付不声称已经解决任意深度查询精度或自动补算。
