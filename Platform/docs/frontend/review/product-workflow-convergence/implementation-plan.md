## 第三批：本次五项意见的实施与验收

1. 移除独立场景编辑实现与导航入口，旧链接转入同一个实验工作台；移除首页流程面板和新建向导，旧向导链接实际渲染工作台。预置案例仍可显式运行，但不再以本地草稿冒充服务器草稿进行派生。
2. 参数分为资源、网络、物理模式、运行；算法设置、对照条件、设备与 TDMA 时序放入有解释的高级折叠区。精确边界见 [参数审计](./closure-review/parameter-audit.md)。
3. 新增 Run 冻结定义只读上下文，核对摘要、资源身份与版本。解决 authored 场景不在静态 catalog 导致的 `ScenarioNotFound`。旧服务没有该接口时，只用真实保留的运行位置进行有限回放，不猜原始配置。
4. 模式 A/B 结果采用紧凑统计表、累计趋势及样本数/最小值/均值/最大值；完整分析可在运行页浮层中打开。物理发送数、旁听、解码和业务交付不混用；缺失的业务分母不编造。
5. 轨迹页提高对比度和字号，起点/深度/速度分量不用手写向量；节点可以显式平移路径并另存资源。时序不变、原资源不变，运行前检查真实轨迹覆盖与 TDMA 计划时长。
