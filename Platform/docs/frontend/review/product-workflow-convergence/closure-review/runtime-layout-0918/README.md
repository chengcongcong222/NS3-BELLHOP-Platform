- 删除横跨页面的多行实验信息带。左栏承接实验名、真实生命周期、当前展示仿真时间、周期进度、编辑/重跑、冻结资源详情和节点列表。

- 底部只保留时间轴工具；原六项底部统计移入右栏紧凑两列表。
- 保持 XY 等比例、固定试验域、上下图相同 X 映射；不为了看起来方正拉伸真实场景。加大坐标/节点文字，避免 X 单位与末端刻度重叠。
