# 产品工作流重新审计与实施方案

日期：2026-09-17。状态：已完成本轮源码审计与规划；以下整改尚未实施。

## 1. 先纠正上一轮结论

上一轮把用户要求拆成了局部控件修改：缩小部分卡片、增加页面链接、合并部分节点字段、增加结果摘要抽屉。
但用户要求的是旧系统的整体任务组织：一个实验、一张画布、随选择变化的检查器、与实验绑定的运行和结果。
“配置页之间能够跳转”不等于“同一个实验工作台”；“把旧事件逐渐播出来”不等于“重新运行一次实验”。
没有完成真实窗口中的逐项任务验收，就把功能测试通过当作完成，是此前交付标准的问题，不是用户描述不清楚。

此次证据为当前源码、默认启动环境内的只读复核、用户本次截图，以及 R4-05 留存的旧版页面截图。
未把历史截图冒充本次实时浏览器证据；未修改产品代码、旧系统或启动服务；未提交、推送。

以下路径以当前树的 `Platform/` 为根，除非特别注明。

## 4. 产品结构：环境、轨迹独立；实验设计、运行、结果统一

一级入口仅保留：工作台、环境建设、轨迹建设、实验编排与仿真。案例库与最近实验归入工作台；系统设置作为次级入口。
场景、实验定义和 Run 仍是后端独立资源，但不要求普通用户在多个产品页面之间手动管理这些引用。
原场景/实验/运行/结果链接保留兼容跳转，打开正确实验与 Run 的上下文，不跳回默认案例。

```text
实验名称 · 保存状态 · 环境名称/版本             保存   保存并运行   历史   结果
平面 / 深度    节点列表    测距                配置 / 运行 / 回放
┌──────────────────────────────────┬────────────────────┐
│ 同一张实验画布                    │ 随选择切换的检查器 │
│ 节点、轨迹、坐标轴、真实通信事件   │ 节点 / 全局 / 事件 │
│ 节点列表按需展开                  │ 参数分组、局部滚动 │
├──────────────────────────────────┴────────────────────┤
│ 播放控制 · 仿真时间刻度 · 事件轨道 · 当前事件统计      │
└───────────────────────────────────────────────────────┘
结果按钮：在当前实验上打开完整分析浮层，关闭后恢复原选择和播放位置。
```

点击节点：名称、角色、收发能力、初始位置、轨迹名称/版本/轨道、绑定状态。
点击背景：环境选择、网络配置、路由、MAC、Channel1/Channel2、业务、运行参数。
点击真实通信事件：该次发送/到达/接收详情；空白处不把 NodePosition 当作通信。
运行中的冻结定义只读；“编辑并再次运行”生成新版本，不修改已有结果所属实验。

保存协调现有场景/实验接口；任何一步失败都显示确切未保存项并禁止启动，不静默选第一场景或旧版本。
稳定关联以正式 ID/版本为准，浏览器临时选中状态只负责编辑体验，不成为 Runtime 权威。
拖动已绑定轨迹的节点不能只改初始坐标：必须明确创建平移后的新轨迹资源再绑定，或提示轨迹固定了位置；不得暗中增加运行时偏移或恢复运动模型。

## 5. 页面细化

### 工作台

以旧首页为母版，主角改回“当前实验”：继续编辑、保存案例/派生、运行、查看最近结果。
保留真实场景缩略图和对应运行摘要；最近实验/历史列表与其并列。资源数量作为小型辅助信息，不再使用一整块大卡片。
没有实验或结果就显示创建入口及空状态，不默认拿 Acceptance 数据或任意最近 Result 填当前实验。

### 环境：选择即查看，查看与编辑使用同一个建设器

左侧为可搜索环境列表，显示名称、地理位置/实际采样位置、水深范围、剖面长度、月份、工作频率、版本、状态。
不存在的坐标或水深明确“未记录”；声学查询最大收发深度不能充当实际海底水深。
主区常驻真实 SSP 与地形剖面，两者均有数值刻度、单位、悬停读数；采样表可展开核对，不能只有一根无法读数的线。
“水文与地形 / 底质与声学计算 / 构建记录”为紧凑参数页签，不同时堆叠六个巨大表单区域。
顶部固定新建、另存草稿、保存、计算、发布；构建进度在本页。已发布版本先只读，“编辑”进入有来源的新草稿，不原地覆盖。
旧独立白色详情页退出普通入口；已有环境没有保存原始剖面时，同一界面如实说明缺失，不能显示当前草稿曲线冒充历史输入。

来源明确分为在线海洋数据、用户文件、内置参考案例。参考案例不可让人以为经纬度可修改；在线不可静默回退。
普通输入只暴露已支持的数据集/统计时段、经纬度、剖面方向、研究距离；高级参数才放采样数、采集深度限制。
研究方向/长度由用户选择，实际水深/可用剖面深度由返回数据决定，二者不是同一种“范围”。
数据范围变化后标记旧采样过期；支持一次采集水文和地形，也允许分别重试，绝不相互改写原始样点。
构建前检查 SSP 覆盖整个所选水柱；不足时给出实际深度差和重新取数/缩小研究范围/导入更完整资料的操作，不静默延拓。
缓存按真实请求及数据集版本追溯；异步请求只接纳仍匹配当前参数的结果，避免旧请求晚返回覆盖新坐标。
Bellhop 输入由草稿快照生成；记录输入摘要、输入文件校验值、真实输出及发布版本，并验证输出坐标轴与输入对应。

### 轨迹

保留独立资源生产端，但普通模式使用“静止 / 直线航行 / 航路点 / 导入文件”。
起点、深度、时长分字段；直线用航向/速度，航路点用表格或地图点选；不要求用户手写逗号分隔的向量。
已有生成接口负责正式计算；显示采样时间范围、当前位置与多轨道切换。UUV 控制/积分参数仅在明确的专家分组中。
从节点检查器打开轨迹选择/建设，完成后返回原节点；静止节点也实际生成并绑定资源，不特殊绕过 Runtime。

### 参数用人话，并与实际作用一致

| 参数 | 正常界面的表达和真实语义 |
| --- | --- |
| CommunicationOnly | “通信性能实验”：产生正常网络业务，研究通信，不启用方位融合；无融合不是失败 |
| BearingFusion | “探测与定位实验”：节点产生方位特征，经网络真实交付后用于融合 |
| minimum bearing observations | “融合所需最少有效观测”：算法启动条件，放业务高级设置；实际收到多少由场景、链路和解码决定，不能由此填出结果；现有限制如至少 5 必须如实显示 |
| maximum fusion period | “融合耗时参考上限（秒）”：当前仅对实测耗时作内部对照，不是定时调度参数，不保证在期限内完成；默认收起且不显示自动验收判断 |
| network update interval = 10 | “每 10 个通信周期更新网络结构和生效调度”：首个、随后第 11、21…周期更新，不是每 10 帧读取一次 TDMA；逐周期状态提交仍照常 |
| guard interval | “时隙保护间隔（秒/毫秒）”：当前 TDMA 配置中的发送时长之外预留间隔，不是接收信号已必然互不干扰的保证 |
| simulation cycles | “运行通信周期数”：不是 wall-clock 秒数；能从正式计划推导时才给预计仿真时长 |
| deterministic seed | “随机种子（复现实验）”：放高级设置，配合同样版本、参数与确定性实现复现；不要求普通用户理解并填写整数 |
| Channel1 / Channel2 | 检查器“物理层”中的显式字段：“通道1：快速抽象仿真 / 通道2：波形仿真”；通道2相邻展开调制、噪声、噪声功率谱密度 |

运行标题使用实际冻结定义的通道选择，不使用未保存表单；没有正式执行器的 MAC/Routing 不做可运行选项。
底层 ns 仍精确序列化，界面用秒/毫秒转换；不能用浮点舍入悄悄改参数。

### 运行、回放与结果

“保存并运行 / 再次运行”真正创建新 Run：清空本次时间轴、计数和视图，再随新事件显现。原历史留在历史列表。
“历史回放”选择已有 Run，完整事件轴可定位。两种模式都能暂停观看、单步、倍速，不能控制第二套仿真时钟。
若 ns-3 很快算完，诚实显示“计算已完成，事件展示中”；为演示逐渐展示是观看策略，不能把旧运行冒充本次新运行。
采用固定且有依据的场景视野、数值坐标轴、等比例 XY。已有资源只有一条地形剖面时，不将它画成完整海区地形。
协议目标链路默认显示，物理旁听为可切换图层；不能为心形视觉删 Runtime 接收，也不把 MAC 的目标节点等同唯一物理接收者。
发送、实际到达、解码/交付、融合用各自真实事件；缺事件就不画。动作与节点位置必须使用同一正式仿真时间。
检查器以可滚动事件表为主：时间、类型、发送者、协议目标、实际接收者、包/特征身份、内容摘要、解码/交付结果；点击行联动画布。
未正式记录完整内容或逐条方位值时显示未记录，不拿发送端原始数据冒充接收端恢复数据。
时间轴加入可读刻度、游标和可筛选事件轨道；筛选仅影响显示，不改变总量统计或事件身份。
下方使用紧凑指标矩阵和小趋势图：发送/交付/失败、链路时延、真实 BER/CRC、报告/有效观测/融合轮次与耗时。按当前观看时间截取全部真实事件统计，不提前使用未来结果。
完整结果浮层沿用现有网络/水声/波形/探测融合分析内容，固定显示本次实验、环境、轨迹版本；关闭保留游标、缩放和选择。

## 6. 视觉约束与复用方法

- 以旧 DOM、SVG、布局和控件回调为母版，再接 DTO adapter；不是只取类名或配色。可复用程度逐组件记录。
- 旧主导航宽约 48 px、紧凑 Studio 检查器 350 px 是起点；是否展开节点列表决定中央比例，不常驻三块大空栏。
- 在 1440×900、1920×1080、浏览器 100% 下检查；普通文字目标 14 px，辅助文字不低于 12 px，不依赖用户缩放到 80% 才能操作。
- 环境首屏同时能见目录、可读剖面、当前参数组和主要动作；非要求把所有高级字段全部展开塞进一屏。
