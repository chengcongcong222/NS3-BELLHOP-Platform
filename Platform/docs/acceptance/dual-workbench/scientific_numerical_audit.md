## 性能与资源

真实 API/Worker 执行 4 节点 3 方向和 6 节点 8 方向。前者无噪声配置首次准入约 0.024 s、首 Run 从提交至完成约 2.159 s、trace 14408 bytes；后者约 0.023 s / 3.174 s / 15406 bytes。各 case 完整原始数值见 `recorded_proxy_run_audit.json`，不将不同长度、调制和缓存条件的差异归因为节点数。

峰值为该 pytest 调用中所有已结束子进程的最大 `ru_maxrss`，4 节点该点 67456 KiB，6 节点该点 77264 KiB；不是独立瞬时 Worker RSS 曲线。ASGI backend 测试进程运行前/首 Run 后/重跑后的 RSS 分别为 62636/63612/64828 KiB 和 73784/74292/75860 KiB，包含该进程保留的测试对象和 trace，不等同于 Worker 缓存。Worker 逐次退出，缓存 run-owned；重复与重启测试验证后续队列仍可执行。A/B 队列等待观测上界及轮询口径见 `run_group_audit.json`。部署资源预算及波形计数门槛见 `contract_and_compatibility.md`。

浏览器首屏计时为保存后实际重新导航到编辑器、等待输入渲染；计时及 JS heap 范围在原始浏览器记录中，不与 Worker 内存混用。
