# ADR-0010：按流规划、正式反馈与不可变算法安装

状态：实施决策已冻结；实现和验证进度见 integration-v2/CHECKPOINT.md。
依据：用户提供 P0-ALG-02 / V1.0，基线 ebd7b1965e011ddaa2fb671305275f97eebec65d。

## 兼容边界

新增 planning-mac-v2，不替换 planning-mac-v1。旧 XML、节点级发送机会、
FIFO、历史运行与 preset 不自动迁移。需要重新编译，不承诺 C++ 二进制 ABI。
不新增物理算法、事件响应协议、私有跨周期算法状态、在线 Bellhop 或第二时钟。

## 数据与执行

1. 新接口只在正式周期边界调用，知识范围固定 global-simulation。路由先冻结，
   MAC 不修改路由。结构来源周期/版本/时刻与本次重绑定来源分别记录。
2. FlowId 是 uint64 强类型，编号 0 合法；HTTP/导出为规范十进制字符串。
   纯通信业务 ID 存入实验修订，不根据表格顺序重算；融合流使用明确的源节点映射。
   DigitalPacket 追加可空仿真流元信息，作为唯一权威；不进入 payload 或波形编码。
   中继必须保留元信息。旧包无流标识仍走旧路径。
3. 需求主键为队列持有节点和 FlowId。新路径只给边界既有包及当周期本地确定输入
   分配预算，不借用未来中继成功。流内 FIFO；选定流为空不改发其他流。
   事件登记成功后按选中 PacketId 条件删除，禁止先取出再放回。
4. 规划预测与真实发送复用 identity-free 声场采样。预测不产生 TransmissionId、
   Trace、噪声或解调。无到达、标量无路径明细、资源错误是不同情况。
5. 上一完整周期反馈由 Runtime 正式接收/交付分支汇总；Trace/SSE 不参与反馈。
   v2 所需波形计数通过 typed Rx result 获取，不消费 observer 回调。
   第 0 周期为 NoHistory；未知误码、无样本不填 0。旧解调因果保持不变。
6. 每条 grant 最多一个包；绑定周期、版本、上下文、流、冻结路由和 grant ID。
   占用仍为正式最大包时长 + 全环境保守尾部 + 非负余量，串行且闭周期。
   新合同允许可选流选择约束；有约束时不能静默走旧 FIFO。

## 配置、身份和安装

XML v2 声明接口、能力、输出和少量参数；默认值在包 XML 中单点定义，完整有效
参数冻结进 Run。与交接书第 10.2 节一致，不在本轮再建立第二套代码默认值权威。
JSON 仅在 worker adapter / backend / 工具，不进入 contracts/planning/runtime。

安装分候选构建、校验、不可变发布、启用。本地管理工具不执行包自带构建脚本，
不下载依赖；受信任原生代码仍须人工审核，接口限制不是安全沙箱。
当前服务默认保持固定 Worker；安装不修改现有设置或杀进程。显式启用通过受控
协调锁避免与运行竞争，并保留旧程序和依赖清单。未受管理的服务不自动切换。
包相同 ID/version 不同内容拒绝发布；失败构建不改变 active 指针。

## 验证

T01–T36 逐项记录，不用旧测试数量充当本轮证据。尤其验证非连续 NodeId、
同源两流选第二流、条件删除、Trace 失败隔离、预测无副作用、候选安装失败隔离、
第二包零核心改动、同一 C++ 算法重放及真实模式 A/B。
