# ADR 0009 编译注册的规划型 MAC 扩展

状态：已实现，适用于规划型 MAC 首版。作为 ADR 0008 的增量，不改变旧实验、周期提交、队列所有权或 ns-3 时间语义。

## 决策

第一版只接入无跨周期私有状态的规划型 MAC。服务器管理员安装受信任 C++ 源码包并重新编译 Worker；XML 只描述参数，不执行脚本，不下载代码。前端读取正在使用的 Worker 提供的目录，不独立维护算法列表。

公开输入为只读 WorldSnapshot、StructureSnapshot、PlanningInput、周期长度及参数。输出为发送机会；平台再次验证时间、节点能力、物理占用及周期边界。算法可以拒绝不适用的场景，但不能修改 Runtime、调度 ns-3 或生成第二套时钟。第一版不接入反应式 CSMA、正交并发 MAC、动态角色选举或 MATLAB。

每个包包含 algorithm.xml 和 algorithm.hpp，可附带同目录头文件。XML 限定字段类型、范围、默认值和基础／高级分组。构建阶段拒绝重复标识、未知语法、DTD、实体和越界文件引用。安装的原生代码是受信任代码，子进程隔离不等于安全沙箱。

## 配置与兼容

PlanningV1 的新 RegisteredMac 分支保存算法 ID、版本、源码包摘要和显式参数；运行冻结时另记录 Worker 文件摘要。未知参数、缺少参数、版本不匹配及包不可用均拒绝执行，不替换成旧 TDMA。默认值仅用于创建新配置，不能覆盖已有实验。

旧 Tdma、AdaptiveTdma 和验收预置路径保持原义。历史结果可以继续查看，重新运行则核对原算法与 Worker。第一版不承诺多版本 Worker 的并行安装；版本不可用时给出明确错误。

## 接入验收

同一输入的内置自适应 TDMA 包与原实现必须产生相同计划。目录、XML 表单、保存、重开、冻结、真实模式 A/B 运行必须贯通。还需验证非法配置拒绝、缺少版本拒绝、外部包编译注册和原案例回归。
